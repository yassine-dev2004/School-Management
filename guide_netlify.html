مشروع نظام إدارة المدرسة الذكية - مدرسة ابن خلدون (Madrasat Ibn Khaldun)

React 18 + Vite + Netlify CI/CD
ملاحظة سريعة للمطور:

خادم الباك إند (Spring Boot) وقاعدة البيانات يعملان بشكل كامل على خادم الـ VPS السحابي، وجميع الـ Endpoints جاهزة ومفعل عليها CORS لجميع النطاقات. عملك ينحصر فقط في واجهة الويب داخل مجلد frontend/ وربطها بحساب Netlify الخاص بك.

1 المتطلبات الأساسية (Prerequisites)

  • تثبيت Git للتعامل مع مستودع GitHub.
  • تثبيت Node.js (الإصدار 18 أو 20 أو أحدث) مع مدير الحزم npm.
  • محرر أكواد (مثل VS Code).
  • حساب مجاني على منصة Netlify (app.netlify.com).

2 استنساخ المستودع والانتقال لمجلد الواجهة

افتح سطر الأوامر (Terminal أو PowerShell) ونفذ ما يلي:

# 1. استنساخ المستودع كاملاً
git clone https://github.com/yassine-dev2004/School-Management.git

# 2. الدخول لمجلد المشروع ثم لمجلد الواجهة الأمامية
cd School-Management/frontend

3 تثبيت الحزم والمكتبات (Dependencies)

داخل مجلد frontend، قم بتثبيت جميع المكتبات اللازمة للمشروع:

npm install

4 ضبط متغير البيئة والتجربة محلياً (Local Development)

قم بإنشاء ملف باسم .env داخل مجلد frontend/ وضع به رابط الـ API السحابي:

# داخل الملف: frontend/.env
VITE_API_URL=https://rio-openings-cognitive-four.trycloudflare.com/api

ثم شغّل خادم التطوير المحلي:

npm run dev

افتح المتصفح على http://localhost:5173، وقم بتسجيل الدخول للتأكد من اتصال الجداول والإحصائيات بالـ VPS بنجاح.

تنبيه هام حول بروتوكول HTTPS في Netlify:

عند نشر الموقع على Netlify، يعمل الموقع تحت بروتوكول مشفر (HTTPS). لذلك يجب أن يكون رابط الـ API يبدأ دائماً بـ https://، لأن المتصفحات تحظر تلقائياً أي استدعاء HTTP عادي من موقع HTTPS تحت ما يسمى Mixed Content Blocking.

5 خطوات النشر على Netlify عبر GitHub (الطريقة التلقائية)

  1. توجه إلى منصة Netlify وسجل الدخول بحسابك.
  2. اضغط على زر "Add new site" ثم اختر "Import an existing project".
  3. اختر GitHub وامنح Netlify إذن الوصول إلى مستودع المشروع (أو قم بعمل Fork للمستودع في حسابك ثم اختره).
  4. اختر مستودع School-Management من قائمة المستودعات.
  5. في شاشة إعدادات البناء (Build settings)، ستجد أن Netlify قرأ ملف netlify.toml تلقائياً. تأكد من مطابقة الحقول:
Base directory frontend
Build command npm run build
Publish directory frontend/dist (أو dist إذا كان Base هو frontend)
  1. اضغط على قسم "Environment variables" وأضف المتغير التالي:
Key (اسم المتغير) VITE_API_URL
Value (القيمة) https://rio-openings-cognitive-four.trycloudflare.com/api
  1. اضغط على زر "Deploy School-Management".
  2. في غضون أقل من دقيقة، سينتهي البناء بنجاح ويمنحك Netlify رابطاً حياً مثل: https://your-site-name.netlify.app!

الطريقة البديلة: النشر اليدوي المباشر (Netlify Drop)

إذا لم تكن تريد ربط حساب GitHub وتريد فقط نشر نسخة جاهزة:

# 1. بناء ملفات الإنتاج محلياً
cd frontend
npm run build

ثم في موقع Netlify اسحب مجلد frontend/dist وأفلته في قسم "Sites > Drag & Drop" وسينشر فوراً.

6 ملف netlify.toml المعد مسبقاً في المشروع

تم تضمين ملف netlify.toml في جذر المستودع وفي مجلد frontend، وهو يضمن معالجة توجيه الـ Single Page App (SPA) ومنع ظهور أخطاء 404 عند عمل Refresh لأي صفحة فرعية:

[build]
  base = "frontend"
  publish = "dist"
  command = "npm run build"

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200

7 استكشاف الأخطاء الشائعة وحلولها السريعة

1. خطأ Network Error أو تعليق عند محاولة تسجيل الدخول:

تأكد من كتابة متغير البيئة VITE_API_URL بشكل دقيق في Netlify (Site configuration > Environment variables). بعد حفظ المتغير، اذهب إلى Deploys > Trigger deploy > Clear cache and deploy site ليعاد البناء بالمتغير الجديد.

2. خطأ 404 عند تحديث الصفحات (Refresh):

هذا الخطأ محلول بالفعل بفضل قاعدة [[redirects]] الموجودة في ملف netlify.toml المرفق مع المشروع.

3. تخصيص اسم النطاق ورابط الموقع المجاني:

يمكنك تغيير الرابط العشوائي إلى اسم مخصص لمدرستك مثل: madrasat-ibn-khaldun.netlify.app عن طريق الدخول إلى Site configuration > Site details > Change site name.
